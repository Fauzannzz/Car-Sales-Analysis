# 🚗 Car Sales Data Analysis with Python & Power BI

## Project Overview
This project delivers an end-to-end car sales analysis using Python for exploratory data analysis (EDA) and Power BI for interactive dashboarding. The analysis aims to identify sales patterns, customer preferences, and key revenue drivers to support data-driven decision-making.

---

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- Power BI
- CSV Dataset

---

## Dataset Description
The dataset contains transactional car sales data with attributes such as:
- Date of transaction
- Customer demographics
- Car specifications (company, model, body style, transmission, color)
- Dealer information (name, region)
- Sales price

---

## Python Analysis (EDA)
The Python analysis includes:
- Data cleaning and preprocessing
- Feature engineering (date attributes, income segmentation)
- Sales trend analysis (monthly patterns)
- Brand and body style performance analysis
- Regional dealer performance comparison
- Customer preference analysis (transmission, color, income level)

---

## Power BI Dashboard
The Power BI dashboard provides an interactive overview of car sales performance, featuring:
- Key KPIs: YTD Sales, MTD Sales, Average Price, Cars Sold
- Sales trends over time
- Performance breakdown by brand, body style, and dealer region
- Detailed transaction-level analysis for deeper exploration

---

## Key Insights
- SUV body styles are the main revenue drivers.
- Automatic transmission vehicles dominate sales volume and average price.
- Sales performance shows strong seasonality, with peaks at the end of the year.
- Significant performance differences exist across dealer regions.
- Neutral colors such as white and black are the most preferred by customers.

---

## Business Recommendations
- Prioritize SUV inventory and automatic transmission models.
- Optimize stock allocation and promotions based on regional performance.
- Leverage peak seasonality (Q4) for targeted marketing campaigns.
- Use entry-level models to drive volume and premium options to improve margins.
